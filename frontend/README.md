# LawLens AI - Legal Document Summarization & Risk Analysis System

LawLens AI parses legal contracts (PDF/DOCX), identifies high-risk clauses, translates summaries into regional languages (Devanagari/Tamil), and generates clean PDF exports.

## Tech Stack
- **Backend:** Python, FastAPI, ReportLab, PyPDF, DeepTranslator
- **Frontend:** HTML5, CSS3, JavaScript
